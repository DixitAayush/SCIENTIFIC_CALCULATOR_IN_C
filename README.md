# Calculator 

A fast, lightweight terminal-based calculator built from scratch in **C**. 

`Calculator` performs fundamental arithmetic and trigonometric operations directly from the command line without unnecessary overhead.

---

## Features

*   **Basic Arithmetic:** Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
*   **Trigonometry:** `sin`, `cos`, and `tan` functions.
*   **Logarithmic Functions:** Standard logarithm calculation (`log`).
*   **Square Root:** Instant square root calculation (`sqrt`).
